# هوية مسار

![Masar brand](brand-sheet.png)

## الفكرة

الشعار حرف **M** مرسوم كطريق واحد متصل: يبدأ من **حلقة مفتوحة** (البداية) وينتهي **بنقطة ممتلئة** (الوصول).
هي نفس فكرة الاسم: مسار واحد واضح من الفكرة للإنتاج.

## الملفات

| الملف | الاستخدام |
| --- | --- |
| `logo.svg` | الشعار الكامل بالإنجليزي على خلفية فاتحة |
| `logo-on-dark.svg` | الشعار الكامل بالإنجليزي على خلفية داكنة |
| `logo-ar.svg` | الشعار بالعربي «مسار» على خلفية فاتحة (العلامة على اليمين) |
| `logo-ar-on-dark.svg` | الشعار بالعربي على خلفية داكنة |
| `mark.svg` | العلامة وحدها: أيقونة التطبيق، صورة الحساب، npm و GitHub |
| `mark-ink.svg` | العلامة على خلفية الحبر |
| `mark-mono.svg` | لون واحد يأخذ لون النص المحيط (`currentColor`): للطباعة والتوثيق |
| `favicon.svg` | نسخة مبسطة بخطوط أسمك، واضحة في مقاس 16 بكسل |
| `palette.css` | الألوان كمتغيرات Tailwind v4: ‏`bg-orange-500` و `text-ink` |
| `palette.json` | نفس الألوان لأي أداة أخرى (Figma، Flutter، العروض) |
| `brand-sheet.html` / `.png` | لوحة الهوية كاملة في صفحة واحدة |
| `fonts/` | خطوط الشعار، برخصة SIL OFL المجانية |

النصوص في ملفات الشعار محولة لخطوط متجهة، فتظهر بنفس الشكل في أي مكان من غير تثبيت خطوط.

وفيه تدرجان كاملان (من 50 إلى 950) للبرتقالي وللرمادي الدافئ في `palette.css`.

## قواعد مهمة

1. **الزر الأساسي يكون برتقاليًا والنص عليه بلون الحبر، مش أبيض.** تباين الأبيض على البرتقالي 3.1:1 وده أقل من الحد المقبول، أما الحبر على البرتقالي فـ6.2:1.
2. **النص البرتقالي على خلفية فاتحة يكون بلون الجمر `#B03700`**، وليس البرتقالي الأساسي، لأن تباينه 5.9:1.
3. **لون الحذف والأخطاء أحمر قرمزي `#C81E3A`** وبعيد عن البرتقالي، عشان زر «إنشاء» ميتلخبطش مع زر «حذف».
4. **البرتقالي لمسة واحدة في الشاشة**: زر، أو شعار، أو تنبيه. لو كل حاجة بقت برتقالي مفيش حاجة هتبان.
5. **مساحة فاضية حول الشعار** لا تقل عن ربع ارتفاع العلامة من كل جهة.
6. **ممنوع**: تدوير الشعار، تغيير ألوانه، إضافة ظلال أو تدرجات عليه، أو تمطيطه.
